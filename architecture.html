Hermes Context Isolation — Architecture

Three-layer LLM conversation isolation — Main Window / Projects / Independent Topics

Key Insight

  • • Don't let the model handle context switching — do it at the API layer
  • • File-level SOUL.md + MEMORY.md per project
  • • bridge.py dynamically injects into system_message
  • • LLM sees ONLY the current project's context

Three-Layer Isolation

  • • Layer 1: Main Window — default conversation space
  • • Layer 2: Projects — SOUL.md + MEMORY.md per project
  • • Layer 3: Topics — independent conversation spaces
  • • Each layer has its own session_key + chat history

Production Status

  • • Running on a 1.6GB RAM VPS
  • • 8 projects + topics actively isolated
  • • Dual entry: Web chat + WeChat
  • • Passed multi-round memory contamination tests
